A클로드 코드 설치

클로드 코드는 유료 요금제(Pro, Max, Team, Enterprise)에서 쓸 수 있습니다. 무료 요금제에는 들어 있지 않습니다.

시작 메뉴에서 PowerShell을 열고 아래 한 줄을 붙여 넣은 뒤 Enter를 누릅니다. 내려받는 동안에는 아무 표시가 없으니 끝날 때까지 기다립니다.

PowerShell에 입력
irm https://claude.ai/install.ps1 | iex

명령 프롬프트(cmd)를 쓴다면 이 줄을 입력합니다.

명령 프롬프트에 입력
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

설치가 끝나면 창을 새로 열고 아래를 입력해 버전 번호가 나오는지 봅니다. 처음 claude를 실행하면 브라우저가 열리고 클로드 계정으로 로그인합니다.

확인
claude --version

설명은 공식 안내(code.claude.com/docs/en/setup)를 따랐습니다. 'claude를 찾을 수 없다'고 나오면 창을 닫았다가 다시 열어 봅니다.

Buv 설치

uv는 파이썬 프로그램을 필요한 부품까지 알아서 받아 실행해 주는 도구입니다. RISS 연결 도구를 돌릴 때 필요하고, 클로드 코드가 파케이 파일을 읽을 때도 씁니다. PowerShell에 입력합니다.

PowerShell에 입력
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

창을 새로 열고 uv --version을 입력해 버전 번호가 나오면 됩니다.

C작업 폴더에서 터미널 열기

클로드 코드는 지금 있는 폴더를 작업 공간으로 삼습니다. 그래서 작업할 폴더에서 터미널을 여는 것이 출발점입니다.

  1. 파일 탐색기에서 작업할 폴더를 엽니다.
  2. 위쪽 주소창을 한 번 클릭합니다. 이때 나오는 글자(예: D:\실습\문헌조사)가 그 폴더의 전체 경로입니다. 뒤에서 경로를 적을 때 여기서 복사하면 됩니다.
  3. 주소창 내용을 지우고 cmd를 입력한 뒤 Enter를 누릅니다. 그 폴더에서 명령 프롬프트가 열립니다.
  4. claude를 입력하고 Enter를 누르면 클로드 코드가 시작됩니다. 끝낼 때는 /exit를 입력합니다.

D처음 만나는 질문 두 가지

1. 이 폴더를 믿느냐는 질문

새 폴더에서 처음 claude를 실행하면 아래처럼 묻습니다. 기본 선택은 No, exit입니다. 내가 만든 폴더라면 ↓로 Yes, I trust this folder를 고르고 Enter를 누릅니다.

실제 화면의 글
Quick safety check: Is this a project you created or one you trust?
Claude Code'll be able to read, edit, and execute files here.

> No, exit
  Yes, I trust this folder

2. 실행해도 되느냐는 질문

클로드 코드는 명령을 실행하거나 파일을 만들기 전에 해도 되는지 묻습니다. 무엇을 하려는지 읽어 보고 괜찮으면 Yes를 고릅니다. 이 자료의 화면은 발표자 PC가 자동 모드(화면 아래 auto mode on)여서 이 질문 없이 진행됐습니다. 여러분 화면에는 질문이 몇 번 더 나옵니다.

E폴더 구성: 자료는 따로, 프로젝트는 그 자료를 가리키게

두 자료 모두 아래 구성을 씁니다. 실습 폴더는 원하는 곳에 만들면 됩니다. 이 자료의 화면은 E:\AI_Work\261027_KLEI_AI_Lecture\실습에서 찍었습니다.

실습\
├─ 자료\
│   └─ nemotron-personas-korea\  ← 페르소나 원본 (파케이 파일 9개, 약 2GB)
├─ 도구\
│   └─ riss\  ← riss_mcp.py, riss_key.txt (키)
├─ 가상응답자_실험\  ← 프로젝트 ①: CLAUDE.md, 설문지.md, 결과\
└─ 문헌조사\  ← 프로젝트 ②: CLAUDE.md, 결과\
  • 큰 원본은 한 곳에 한 번만. 2GB짜리 페르소나 자료를 프로젝트마다 복사하지 않고 자료\에 두고 같이 씁니다.
  • 위치는 CLAUDE.md에 적어 둡니다. 클로드 코드는 시작할 때 그 폴더의 CLAUDE.md를 먼저 읽습니다. 자료 경로와 작업 규칙을 적어 두면 매번 말하지 않아도 됩니다.
  • 원본은 읽기만. CLAUDE.md에 '고치거나 지우지 않는다'고 적어 둡니다. 결과는 프로젝트의 결과\에 쌓입니다.
  • 키는 도구 폴더에만. riss_key.txt는 메일, 단체 대화방, 깃허브 같은 곳에 올리지 않습니다.
  • 코덱스(ChatGPT)를 쓴다면 같은 내용을 AGENTS.md라는 이름으로 둡니다. 코덱스는 이 파일을 읽습니다.
