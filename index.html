"AI가 내 자료를 학습할까?"

파일 첨부와 지시는 작업 기억에 넣는 일, 학습은 모델의 가중치를 바꾸는 일

학습이 아님(in-context)

  • 파일 첨부, 프로젝트에 자료 올리기
  • 지시문, 대화 중 수정 요청
  • 가중치는 그대로, 자료가 크면 필요한 부분만 찾아 넣음(RAG)

학습(가중치 갱신)

  • 사전학습: 대량의 글로 다음 단어 예측
  • 파인튜닝: 추가 자료로 모델을 더 학습
  • 사용자가 허용한 대화를 다음 모델 학습에 쓰는 경우

/context컨텍스트 사용량을 격자로 보여 줌무엇이 공간을 차지하는지 볼 때
/compact [초점]지금까지의 대화를 요약해 공간 확보, 요약 초점 지정 가능같은 작업을 이어 갈 때
/clear빈 컨텍스트로 새 대화 시작다른 작업으로 넘어갈 때
/resume이전 대화를 다시 엶clear 뒤 예전 대화로 돌아갈 때
/usage세션 비용, 요금제 사용 한도 표시한도와 사용량 확인
작업 이력 기록지금까지 한 일을 Working_history.md 같은 파일에 적게 함compact·clear 직전
CLAUDE.md세션마다 읽히는 프로젝트 지시, compact 뒤에도 다시 들어감오래 지킬 규칙
Shift+Tab권한 모드 전환, 계획 모드에서는 파일을 고치지 않고 계획만 제안큰 작업 전 계획 검토
Esc진행 중인 작업을 바로 멈춤방향이 틀렸을 때
주: compact는 요약이라 도구 출력과 중간 추론은 사라짐. 그래서 이력 기록을 먼저 함.
